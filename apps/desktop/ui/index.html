                      Экспериментальные функции
                      

                      Необязательные механики, которые ещё не стали настройками по умолчанию. Некоторые действуют только после перезапуска браузера.
                      

                      Мультимедиа
                      


                      По умолчанию APB блокирует автозапуск: видео не стартуют сами, пока вы не кликнете. Включите — чтобы сайты снова запускали медиа сами. Действует после перезапуска.
                      

                      Буфер обмена
                      


                      Перехватывает копирование на страницах (Ctrl+C / контекстное меню) и дополнительно пишет текст в системный буфер. Нужно, если скопированное иногда «пропадает» при быстром переключении в другое окно. Действует сразу.

                        • **жирный**, *курсив*, ~~зачёркнутый~~

Что можно делать в графе


                        

                        

                        

                        🧭 Навигация
                        

                          

                        • Колесо мыши — зум
                          • 

                        • ПКМ / СКМ + тянуть по фону — панорама
                          • 

                        • Одиночный ПКМ по пустоте ничего не открывает
                          • 

                        

                        

                        

                        ➕ Создание
                        

                          

                        • 2×ПКМ по фону — меню создания (заметка, текст, картинка)
                          • 

                        • 2×ЛКМ по фону — новая заметка сразу
                          • 

                        • Текст в блоках правится на месте
                          • 

                        

                        

                        

                        🔗 Связи
                        

                          

                        • ПКМ + тянуть от фигуры — провести связь
                          • 

                        • ● точка на краю карточки — тянуть связь левой кнопкой
                          • 

                        • Клик по линии — выбрать, Del — удалить
                          • 

                        • [[вики-ссылки]] в заметках становятся связями
                          • 

                        

                        

                        

                        ✂️ Выделение и удаление
                        

                          

                        • ЛКМ-рамка по фону — выделить группу
                          • 

                        • Тянуть выделенное — групповой перенос
                          • 

                        • Del — удалить блоки и линии (заметки-файлы не удаляются)
                          • 

                        • Esc — снять выделение
                          • 

                        

                        

                        

                        ↩ История
                        

                          

                        • Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y — отмена и возврат
                          • 

                        • ✨ Уложить — переложить граф физикой
                          • 

                        • 🧹 Очистить поле — убрать блоки (заметки останутся)
                          • 

                        

                        

                        

                        🔎 Прочее
